# Original Laema art with AI

Research goal clarified by the user on2026-10-23: discover how to create better original artwork with AI, including the original character Laema. The earlier HoMM3 Pikeman work is a technical benchmark for consistency, control and cleanup; remastering that asset is not the overarching goal.

Current experiment: [local Qwen versus built-in image generation](local-trials/2026-10-23-local-vs-imagegen-v01/README.md). It uses existing approved concept references, two shared briefs and untouched first results, with user visual review required before accepting any art or method.

Reusable local setup: [ComfyUI Laema Apps](ComfyUI-Laema/README.md), with root Start/Stop launchers, preset references, a prompt form and five selectable model configurations. Actual UI generation and restart checks were executed. No Codex conversation is needed to operate these local workflows.

Expanded comparison: [ten first outputs across five configurations](local-trials/2026-10-23-local-model-survey-v01/REVIEW.md). Qwen, FLUX2 Klein Base/Fast and LongCat share a single reference and briefs; Z-Image is a separately labelled text-only track. Gated models remain unexecuted. User artistic review is pending.

All work here is isolated research. Existing character alternatives, production assets, gameplay and other animation research remain in their existing roles.
