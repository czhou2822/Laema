# Reproduce the bounded local Pikeman trials

All new work is confined to this folder plus an ignored disposable runtime/model cache. No production binding is changed. Do not overwrite an earlier completed raw experiment; choose a new trial folder when changing settings.

1. Read `preservation.json`, `hardware.json`, `model_lock.json` and `REPORT.md`.
2. Set `LAEMA_HOMM3_CACHE` to a dedicated local directory with room for the models, environment and temporary chunks. Use a directory outside sync folders. The initial run's cache location is recorded as provenance in the runtime locks/commands.
3. `python bootstrap.py setup` creates a separate venv and the pinned ComfyUI checkout. `python bootstrap.py models` downloads official model bytes by pinned revision, validates exact range responses and verifies SHA256 before use. Successful installation/model transfer is not inference evidence. Downloaded weights are not included in the research deliverable.
4. `python run_local.py server` starts the offline ComfyUI API on127.0.0.1:8189 with custom/partner nodes disabled. It uses only the model cache and this folder's inputs. `server.log` records the actual startup and execution boundary.
5. `python run_local.py run reference 0 5` executes two fixed-seed structural scouts. `python run_local.py run masked 0 1 2 3 4 5` executes six unique restored-source + recovered-master edits. Raw RGB outputs, actual API graphs, node schemas, execution history, duration and GPU samples are saved per image. Scripts skip existing outputs. No Lightning LoRA is used. Both methods request608×416,40 steps, true CFG 4, Euler/simple, seed 42, AuraFlow shift 3.1 and CFGNorm 1. The masked variant initializes from restoration, uses denoise 0.35 and an opaque-source mask dilated4 guide pixels to limit noise. This is generic mask guidance, not a ControlNet.
6. `python compare.py` makes explicitly imposed-alpha derivatives and packages a complete method only when all six unique outputs exist. The exact original repeat map is deterministic. Ten full900×800 frames and a3600×2400 four-column atlas preserve2× source offsets/anchor. Raw results remain untouched.
7. Optional actual engine appearance: `python prepare_engine.py` copies the tracked engine dependencies into the disposable cache and imports only that copy. `python capture_engine.py baseline-gpu` or a new phase name invokes the actual renderer. Never reuse a completed phase. `python engine_comparisons.py PHASE` assembles saved captures. Existing crash logs and renderer limitations are part of the evidence.
8. Open `review.html` directly, or serve this folder on loopback with `python -m http.server 8191 --bind 127.0.0.1`. No external hosting is needed. All playback uses provisional100ms dwells; no original timing or combat feel is established.

`prepare_inputs.py` was used for the original recovery/inventory. It contains the discovered Art scratch path as evidence and copies selected input/provenance bytes. Its source baselines must exist before running. For another computer, use the already recovered portable inputs and records, or explicitly supply the appropriate local Art root; do not interpret the old cloud `/workspace` paths as current local paths.

The built-in reference scout has a separately saved prompt/input set and opaque backend. Its exact output is preserved but cannot be regenerated byte-identically from a seed/version the tool did not expose. `builtin-scout/measure_scout.py` reproduces its deterministic comparison and partial weapon fallback only.

No candidate or method is accepted. User visual review precedes adoption; production replacement and publication need separate user instructions.

## Additional executed comparisons

See `QWEN_RESULTS.md` and `execution_summary.json`. `continue_trials.py` executes the larger ready canvas, low-strength no-mask ablation,0.65-strength thrust and remaining low-strength poses. `last_scout.py` executes one full-strength masked thrust after the complete group. `finalize.py` validates the atlas, original repeat map and supplied-evidence hashes and rebuilds review sheets. All scripts skip completed raw trials. These execution records, rather than a prepared graph alone, establish what ran.

For engine reproduction set `LAEMA_GODOT_PATH` to the installed Godot executable, unless `godot` is on PATH. For input recovery set `LAEMA_ART_SCRATCH` to the recovered Art package root. Actual initial paths are provenance in `hardware.json` and `package-inventory.json`; the scripts no longer hard-code this computer account.

## Stable24GB GPU recovery settings

For the successful final recovery on this machine, set `LAEMA_COMFY_STATIC=1`, `LAEMA_COMFY_CACHE_NODES=32` and `LAEMA_COMFY_RESERVE_GB=6` before `python run_local.py server`. The two interrupted low-headroom attempts produced no raw image and remain in `masked-full/attempts/`. To reproduce the full-strength sequence use `python run_local.py run masked-full 0 1 2 3 4 5`; completed files are skipped. `runtime-policy-by-run.json` records which memory profile actually produced each image. The final comparison phase is `final-complete`.

`requirements-inference-lock.txt` locks the76-package inference dependency closure used here, including the shared Pillow/NumPy versions. Bootstrap prefers this lock after installing the pinned official CUDA Torch wheel. Preserved raw outputs provide exact comparison bytes; cross-hardware numerical identity is not guaranteed.
